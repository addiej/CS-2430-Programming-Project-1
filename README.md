Project Description:
This project compares the number of element-to-element comparisons performed by four sorting algorithms:
Merge Sort
Quick Sort
Shaker Sort
Heap Sort

The program generates every permutation of the integers from 0 through n - 1 for n = 4, 6, and 8. Each permutation is sorted by all four algorithms, and the number of comparisons is recorded.

Requirements for program execution:
Python 3 Installation

Files:
main.py
(Runs the experiment and collects results.)
permutations.py
(Generates all permutations of the input values.)
mergesort.py
(Implements Merge Sort.)
quicksort.py
(Implements Quick Sort.)
shakersort.py
(Implements Shaker Sort.)
heapsort.py
(Implements Heap Sort.)
docs/
(Contains project planning, design, testing, pseudocode, and contribution documentation.)

How to Run
Download or clone the repository.
Open a terminal in the project directory.
Run main.py.

Experimentation:
The experiment runs each sorting algorithm on every permutation for:
n = 4
n = 6
n = 8
For each algorithm and value of n, the program records:
1. The original unsorted array
2. The number of element-to-element comparisons
3.The 10 inputs requiring the fewest comparisons
4. The 10 inputs requiring the most comparisons
5. The average number of comparisons
